### main 移动端首页优化（已纳入主线）

用户当前要求：选定 A“贴左常规字号”；保留缩小后的移动端工具栏；`INTERVALS` 禁止横向拉伸变形，初始为白底蓝字，下滑时首图进入字标区域，落在图片上的字按真实交界逐步变白；接近首图下方正文时，同一个字标丝滑缩小上移至品牌图标右侧，并渐变为墨黑，终点显示参考图中的 `INTERVALS / EAR TRAINING` 组合。二级及更深页面直接常驻同一完整品牌组合；彻底隐藏手机右侧滚动位置条但保留正常手指滚动。手机系统返回应退回应用内上一层，但答题中必须拦截系统返回，只能点击“× 结束”。电脑端继续保留原有字标收放按钮与滚动行为。

当前实现（主要位于 `src/App.tsx` HomeView、`src/App.css` 与 `src/App.test.tsx`）：

- 移动端字号层级保持「Hero 标题 46 → 区块引言 20 → 卡片标题 34 → 正文 15/13 → 微标签 10」；顶栏为 50px，390px 及以下为 46px，品牌标与控件同步缩小。
- 字标固定在移动端顶栏下方，采用 A 贴左常规字号，只改变字号、不使用 `scaleX`；B 满屏方案、临时选择器与 `intervals.mobileMastheadWidthPreview` 均已移除，旧存储键会在首页加载时清理。
- 蓝色字标与白色字标层完全重合，白色层按首图和字标的实时交集裁切：图片未进入时全蓝，进入多少就变白多少，完全进入后全白。两层均为装饰性结构，用户视觉上只看到一个连续变色的字标。
- 字标接近首图正文前，以单一 DOM 字标完成 0.56 秒缩小上移和蓝/白到墨黑的颜色过渡，终点与顶栏隐藏占位的 `INTERVALS` 精确重合，只让 `EAR TRAINING` 延迟显现；不再使用两份 `INTERVALS` 交接，避免基线差导致停顿或二次上移。缩小与放大沿用当前页面随滚动事件即时判定的原始手感，不增加静置等待；首次定位的 350 毫秒仅用于无过渡落位，不改变后续滚动响应。
- 非首页顶栏显示“品牌图标 + INTERVALS + EAR TRAINING”；手机端对 `html`、`body`、`#root` 和应用外壳统一隐藏滚动位置条但保留文档滚动，320px 极窄屏按比例缩小品牌与控件，不隐藏品牌副标题。
- 手机端使用轻量 History API 记录分类、设置、错题和结果页面；系统返回按历史退回上一层。`quiz` 状态会恢复被返回手势移开的历史位置并保留当前题，只有页面内“× 结束”会按 `quizExitView` 退出。
- 手机行为由 `matchMedia('(max-width: 700px)')` 门控；桌面端恢复 `main` 原有收放按钮、自动收起和展开逻辑，白色裁切层不显示。

未验收/下一步：用户 2026-08-31 决定停止继续叠加动画触发修复，保留 `b697ca1` 所代表的最初手机交互体验，并把这一 UI/交互范围合并到 `main`；真机反馈中的中途误触发与返回闪动不在本次继续修改。主线不合并 `codex/furch-audio-preview`，也不提交本地 `furch-Sample/`。
