# 项目决定

这里只记录已经明确接受、拒绝或被替代的具体取舍。产品原则见 [`PRODUCT.md`](PRODUCT.md)，实现边界见 [`ARCHITECTURE.md`](ARCHITECTURE.md)，未确认想法见 [`IDEAS.md`](IDEAS.md)。

状态：`Accepted` 当前有效；`Rejected` 明确不采用；`Superseded` 已由另一决定替代；`Needs confirmation` 证据不足，不能作为实现授权。

## D-001 共享规则优先于页面补丁

- Status: `Accepted`
- Confirmed: 2026-08-25
- Decision: 乐理拼写、记谱、题目身份、答案焦点、键盘行为和播放调度优先在共享 domain/service/component 层修复，并以回归测试覆盖，再接入具体练习。
- Avoid: 为一个页面复制近似函数、硬编码一个和弦示例、用 CSS 或条件分支掩盖缺失的共享规则、借机无限重构。
- Reason: 项目将继续增长；局部补丁会导致显示、声音和不同练习之间漂移。
- Review trigger: 当新模块让导航、界面或代码明显趋于杂乱时，从训练目标和共享边界重新评估是否需要有限重构；候选功能本身不构成提前搭建空框架的理由。

## D-002 0.x.x 版本与发布口径

- Status: `Accepted`
- Established: 2026-08-11
- Decision: 正式市场发布前保持 `0.x.x`。一组重要功能增加 minor，小修复或小优化增加 patch；进入真实市场检验时再考虑 `1.0.0`。
- Release contract: `package.json`、`package-lock.json`、`CHANGELOG.md`、Git 标签和 GitHub Release 保持一致，Pages 必须实际验证。
- Avoid: 仅因代码合并就声称在线版本已更新。

## D-003 和弦练习保持浅层导航

- Status: `Accepted`
- Established: 2026-08-11
- Decision: 三和弦与七和弦可以作为清楚的同级分类；Drop 2 与 Shell Chord 在同一七和弦设置流程中并列，不继续增加深层菜单。
- Avoid: 为每个 Voicing 新增一层相似设置页，或让分类层级遮蔽“现在该做什么”。

## D-004 七和弦 Voicing 的答题协议

- Status: `Accepted`
- Established: 2026-08-11
- Decision: 作答前只显示和弦名，让用户用 `R / M3 / 5 / M7` 基础成员及降号切换组装由低到高的顺序；作答后再显示正确排列、音名和谱面。
- Patterns: Drop 2 的内部结构 ID 使用 `5R37`、`37R5`、`735R`、`R573`；Shell 使用 `R37`、`R73`。其中 ID 中的 `3 / 7` 是紧凑结构简写，实际成员显示遵守 D-008 的 `M3 / M7` 规则。
- Avoid: 作答前直接泄露排列或答案音名。

## D-005 真随机感、覆盖、选项稳定与相邻去重

- Status: `Accepted`
- Established: 2026-08-08
- Decision: 题目内容与和弦转位不能按可预测的固定顺序循环；需要覆盖时先满足明确覆盖规则，其余选择保持不可预测。前后两题不能完全相同，并且跨轮次避开上一轮末题与下一轮首题重复；一轮内允许非相邻重复。
- Interval options: 音程答案选项的位置保持稳定，并根据用户本轮选择的测试范围缩减，不因换题不断重排。
- Avoid: 用伪随机固定轮转让用户猜顺序；把 “Do not repeat” 解释成整轮每题必须唯一；为了随机感破坏必要覆盖。

## D-006 播放音域、速度与取消

- Status: `Accepted`
- Established: 2026-08-08; refined 2026-08-12
- Decision: 主要最终声部保持在约 G3–F5（MIDI 55–77）范围；四小节和弦进行约 `123.2 BPM`；V–I–目标音使用较慢的独立速率。为满足和声连接可以先保留更宽的候选，再筛选最终声部。
- Cancellation: 切题、退出、重播、切换播放方式/音色和卸载时，停止当前声音并取消尚未触发的延迟音符与回调。
- Avoid: 只调用 sampler `releaseAll()` 却留下定时器，或过早缩窄候选导致进行生成失败。

## D-007 首次使用文案与反馈强度

- Status: `Accepted`
- Established: 2026-08-06; refined 2026-08-12, 2026-08-25
- Decision: 首页、导航、设置、答题、反馈、结果、错题和安装路径都应让第一次使用的人知道下一步；先解释操作，再出现专业术语。对错反馈要克制但能感知。Closed 与 Spread 三和弦的答案解析按根音构成、转位与实际音名、唱名、成员关系分行；Spread 的转位由最低声部决定，并保留排列 ID 作为辅助信息。三音/五音题按“内部两个三度、外框根音到五音、目标答案”分行；Drop 2 与 Shell 的解析不重复题目标题中的和弦名，统一写成“排列是：……”与“组成音是：……”，并使用相同的分行与重点强调样式。
- Avoid: 只审查某一个页面的文案、使用术语代替操作说明、让动画或声音盖过学习内容。

## D-008 标准记谱与爵士符号

- Status: `Accepted`
- Established: 2026-08-11; refined 2026-08-12, 2026-08-25
- Decision: 调内练习使用正确调号、临时升降号状态、拍号和小节线；非谱面音乐符号使用共享 Bravura/SMuFL 语义组件，并按教材、和弦谱和常见手写习惯调整实际视觉重心。音名序列使用带克制留白的短横线；和弦根音升降号可略小、略高，普通音名保持文本音乐字形的自然位置。成员关系统一为：根音 `R`；大七度 `M7`、小七度 `♭7`；大三度 `M3`、小三度 `♭3`；纯五度 `5`、减五度 `♭5`。成员符号中的 `5` 使用与衬线字母协调的等高数字，避免旧式数字视觉下沉。爵士大七使用空心粗三角 `△`，不用实心 `▲`。
- Avoid: 用重复普通字符模拟重升降号、直接用正文 `b` 或松散 Unicode 字符拼接 `♭3/♭5`、让升降号碰到分隔线、用等音 MIDI 值忽略正确拼写、让 UI 字体覆盖音乐符号、让成员 `5` 使用下沉的旧式数字，或把所有语境机械套成同一基线/上标规则。

## D-009 运行时资产与本地源素材分离

- Status: `Accepted`
- Established: 2026-08-12
- Decision: PWA 运行需要的压缩 MP3 与字体进入版本控制和离线缓存；原始 FLAC、论坛归档和本地素材保留在被忽略的 `.local-assets/`、`Drop/` 等路径。音源优先考虑音质高且授权负担低的材料，但任何实际采用的采样或录音都必须确认可再分发范围并保留完整署名与许可说明。
- Avoid: 把“大概没有版权”当成许可证明；把大体积源素材提交到 Git；或在替代资源未通过全新 clone 构建/播放验证前删除现有有效资源。

## D-010 发布必须验证真实结果

- Status: `Accepted`
- Established: 2026-08-12
- Decision: 收到“提交、上传、更新”类要求时，完成后报告目标 commit、远端分支、Pages workflow、稳定 URL、真实页面行为以及缓存/更新机制。
- Avoid: 只报告本地提交、只看 workflow 配置、或因为一个带旧缓存的浏览器页面就下结论。

## D-011 直接试听是学习解释的一部分

- Status: `Accepted`
- Established: 2026-08-06; refined 2026-08-08, 2026-08-25
- Decision: 答对后自动播放正确答案。音程作答后探索其他选项时固定原题低音，只改变高音并显示对应音名；和弦填音完成后，无论对错都允许试听已填写的音或自己的完整答案。所有练习中出现的五线谱都为每个实际谱头提供点按/键盘试听，统一播放该谱头的真实音高和当前音色。
- Avoid: 播放与原题低音不一致的示例；只允许答对者探索答案；点击显示和实际声音不一致。

## D-012 和弦入口图形必须提供音乐暗示

- Status: `Accepted`
- Established: 2026-08-11
- Decision: 和弦入口使用能够表达和弦或 Voicing 结构的轻量谱面图形；Drop 2 图标应暗示“第二高音下移八度”。不需要额外的橙色角标来表示分类。
- Avoid: 使用与和弦无明显关系的抽象三角形、纯文字缩写或重复分类角标。

## D-013 音程集合以训练实用性为准

- Status: `Accepted`
- Established: 2026-08-11; refined 2026-08-12
- Decision: 练习内容不追求穷举理论上所有增减音程；优先保留实际训练价值明确的变化音程。增七度明确不进入当前进阶音程集合。
- Avoid: 仅因理论上存在就增加极少使用、容易分散训练重点的题型。当前精确集合由代码与 `CHANGELOG.md` 维护。

## D-016 手机系统返回与测验退出边界

- Status: `Accepted`
- Confirmed: 2026-08-28
- Decision: 手机端进入首页以下的分类、设置、错题与结果界面时，把浏览器或系统返回操作映射到真实的上一层应用界面。进入 `quiz` 答题状态后拦截系统返回并恢复当前历史位置，不退出、不清空题目；结束本轮只能通过页面内明确可见的“× 结束”按钮，并继续沿用各练习类型已有的退出目标。
- Scope: 当前只在加载时为移动端视口启用轻量 History API 状态；不引入 URL 路由，也不改变桌面导航或页面内已有返回按钮的目标。
- Avoid: 手机返回直接离开 PWA；答题中因返回手势丢失进度；拦截后停留在错误历史位置；为了该行为引入完整路由依赖。

## D-015 移动端首页层级与字标图片交界变色

- Status: `Accepted`
- Confirmed: 2026-08-27；2026-08-28 根据用户提供的 LOEWE 与完整品牌组合参考，确认交界变色、A 贴左与顶栏回收规则
- Decision: 移动端（≤700px，含 390px 断点）首页采用以下规则：①字号形成「Hero 标题 46 → 区块引言 20 → 卡片标题 34 → 正文 15/13 → 微标签 10」的分级台阶；②顶部工具栏保留但缩小（50px，小屏 46px），品牌标与图标同步缩小；③大字 `INTERVALS` 使用 A 贴左常规字号，保持自然字形比例，只改变字号、不横向拉伸；④初始为白底蓝字，下滑时首图进入固定字标区域，只有与图片相交的字形部分按交界逐步变白，视觉上始终保持一个连续字标；⑤缩小与放大沿用当前页面随滚动事件即时判定的原始手感，不增加静置等待；缩小用首图正文接近顶栏与原字标之和的判定，放大沿用页面顶部阈值；⑥从二级页面返回首页或首次定位时，回收/展开状态直接落位、不播放复位动画；⑦二级及更深页面的顶栏直接常驻“图标 + INTERVALS + EAR TRAINING”完整品牌组合；⑧页面仍完全跟随用户原始滚动，但手机端不显示常驻滚动条。桌面端继续使用 D-014 的原有字标尺寸、收放按钮和滚动行为。
- Scope: 只覆盖移动端首页的字号层级、顶栏尺寸、字标自然比例、蓝白交界、品牌回收动效、非首页品牌识别与滚动条外观；二级页面工具栏功能（音色、记法、错题）及桌面首页行为保持不变。B 自然比例满屏方案与临时 A/B 选择器已移除。
- Avoid: 使用 `scaleX` 等非等比变换把字形硬拉满；用两份基线不同的 `INTERVALS` 交接而产生停顿或跳位；同时显示两个可辨认的完整蓝/白字标；把移动端工具栏整体隐藏；让字标动画改变页面高度、吸附滚动或替用户推动页面；在手机右侧保留破坏构图的可见滚动条；在手指仍在滑动时就判定缩小或放大，导致大图区域轻微回滑就反复播放动画；回到首页或初次定位时播放多余的复位/展开动画；照搬 LOEWE 具体页面细节（延续 D-014 的 Avoid）。

## D-014 编辑式视觉基线与音乐文化边界

- Status: `Accepted`
- Confirmed: 2026-08-25；2026-08-26 根据真实首页审看定稿；2026-08-31 根据超宽桌面审看收紧比例
- Decision: 第一阶段采用照片优先、高留白、低信息密度的编辑式首页。最终结构为 D：白底蓝色 `INTERVALS`、原始大近景、白色文案和统计直接叠在照片底部；字标字体采用评审中的 B 高反差衬线版，可点击细线箭头收放，也会在页面下滚时收起。主图默认使用保留透明音叉与原始构图的“纯净清晰”4K WebP；胶片颗粒版本保留为资产但不在界面提供切换。下方入口采用低密度编辑目录：亮蓝、朱红、荧光黄绿和暖白仍从主图取色，但每张照片保留约三分之二干净色面，只用少量真实材质对象表达功能关系；音程强调两个音与距离，和弦强调多个音的聚合，调强调中心与周边关系，离线强调一个可独立携带的练习单元。桌面保持带白色间距的 `2 × N`，宽屏卡片高度封顶；手机采用约 `3 : 2` 的单列图片流。未来出现奇数个模块时，桌面最后一项使用全宽但约半高的横幅，手机仍回到普通单列，避免为了当前四项写死结构。共享顶部导航采用轻字重排版、细分隔和统一浅灰细线图标：记法使用评审 B、错题使用评审 A，古典吉他暂用正向竖直的镂空琴头，并按与横向钢琴相近的视觉面积校准。桌面首页编辑画布最大宽度为 1520px，超宽屏通过增加外部留白而不是继续放大内容；桌面主图采用 `16 : 9`，字标上限 138px，主图标题与入口标题上限分别为 52px 与 46px，和二级页 48px 标题形成连续尺度。700px 及以下继续使用 D-015 的移动端层级与主图比例。音乐文化通过唱片封套式近景、目录编号、印刷色和谱面关系进入结构；练习页继续让谱面、题目、作答和试听保持第一优先级。
- Scope: 当前完成首页大体结构、配色、留白、构图、字体层级、共享顶部导航和轻量收放动效；更细的艺术处理后续再补。胶片颗粒只允许存在于备选主视觉摄影，不覆盖功能内容。比波普解构与“拆开声音再重新理解”的训练隐喻保留为后续独立分支，不与当前首页方向混合。
- Avoid: 照搬 LOEWE、Bottega Veneta、Teenage Engineering 或 Ableton 的具体页面；用与主图无关的色块破坏统一；让字标与背景同色而吞字；用过厚字标挤压主图；为了补全物体轮廓把大近景缩成小型产品照；使用含义不清、像塑料或亚克力玩具的生成式功能图标；混用粗黑底板、Emoji、药丸控件和细线编辑体系；让纹理和形式感遮盖学习动作。
- Review result: D 首页结构、B 字标和“纯净清晰”默认主图已经选定，临时 A/B 与主图质感选择器均已删除；胶片版留档，只有用户以后明确要求时才重新接入。2026-08-26，用户进一步确认下方入口采用上述“桌面低密度双列、手机节制单列、可继续扩展”的方向；模块文案采用左下分组的编辑式层级，和弦红降低亮度并使用暖白文字。浏览器标签和 PWA 安装图标复用同一音程关系线标，小尺寸图标不塞入完整 `INTERVALS` 字标。2026-08-31，用户指出超宽桌面首页整体和文字过大、进入二级页后尺度跳变明显，确认改为画布限宽与首页/二级页连续字号层级；手机端不随此次调整改变。
